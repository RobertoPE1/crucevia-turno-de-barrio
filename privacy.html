Saves and platform privacy

Crucevia saves completed districts, stars, best scores and a checkpoint of the current shift under crucevia-campaign-v2. The checkpoint includes the stage, timer, lives, signals, vehicle/pedestrian positions and counters. There are no names, messages or contact details in that save.

On CrazyGames, the game uses the official SDK Data module. According to CrazyGames documentation, guest saves are stored in the browser and signed-in saves can sync to the platform account. Sync depends on the platform and network; the game does not promise immediate synchronization. If Progress Save is unavailable, the game shows a warning and keeps progress only for the current session.

Outside CrazyGames, if SDK storage is unavailable, the game uses local browser storage. You can remove local saves by clearing this game's site data; platform account data is managed through CrazyGames. The previous numeric best score may be imported once from crucevia-record when no campaign save exists.

The SDK is loaded from sdk.crazygames.com and reports when gameplay starts/stops. Loading it makes a network connection to CrazyGames. Read the CrazyGames Privacy Policy for platform processing and privacy choices.

The game's own code adds no account system, forms, chat, ad requests, purchases or separate analytics service. This notice does not claim the platform processes no data. For developer identification/support, use the game's CrazyGames listing. A standalone publisher must supply its applicable identification/contact details.
