Storage and platform privacy

Crucevia stores only a numeric best score under crucevia-record in this browser's local storage. The game does not send that score to its developer. You can remove it by clearing this game's site data in your browser. The game remains playable when storage is unavailable.

This build loads the official CrazyGames SDK from sdk.crazygames.com. It reports when gameplay starts and stops. Loading the SDK also makes a network connection to CrazyGames. Platform data processing and privacy choices are described in the CrazyGames Privacy Policy.

The game's own code adds no account system, contact forms, chat, advertising requests, purchases, or separate analytics service. This notice describes the game code; it does not claim that the CrazyGames platform processes no data.

For developer identification and support, use the developer information provided in the game's listing on CrazyGames. A standalone publisher must supply its own applicable identification and contact information.
